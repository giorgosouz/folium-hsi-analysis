# Folium HSI Analysis

Interactive mapping notebook focused on HSI-related visualization with Folium and WMS sources.

## Repository contents
- `lb4.ipynb`: main notebook
- `gbda_lab_4.pdf`: lab report and supporting write-up
- `LICENSE`: license file

## Usage
- Open the notebook in a Jupyter environment with the required geospatial dependencies installed.
- Use the report for additional context on the mapping workflow and outputs.
